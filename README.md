# Cocktail

> 📚 **Learning project.** An animated cocktail bar landing page, built by following a tutorial.

- **What I learned:** scroll-driven animation with GSAP ScrollTrigger, text-reveal effects with SplitText, and scroll-scrubbed video playback.
- **Built with:** React, Vite, Tailwind CSS, GSAP, `react-responsive`.
- **Run it:** `npm install && npm run dev`
